# Протокол встречи: Интервью с заказчиком по рынку аренды жилья

Дата: 21.11.2026 · Участники: Заказчик (Преподаватель), Аналитик (@wwind01) · Ведёт протокол: @wwind01

## Повестка
1. Уточнение требований к аналитическому отчёту по аренде квартир в Москве.
2. Определение приоритетных районов и типов жилья для анализа.
3. Согласование формата итогового продукта.

## Список вопросов
1. Какие районы Москвы и типы квартир являются приоритетными?
2. Нужен ли разбор условий залога и комиссий риелторов или фокус только на ценах?
3. Какой формат результата наиболее полезен (дашборд, отчёт, база данных)?
4. Стоит ли включать анализ ограничений по животным и детям?
5. Какие источники данных лучше использовать (Циан, Авито, ДомКлик)?
6. Есть ли ограничения по бюджету на инструменты визуализации?
7. Как часто нужно обновлять данные для поддержания актуальности?
8. Каковы главные критерии успешности проекта для вас?

## Что обсудили и решили
- Заказчик подтвердил, что фокус должен быть на 10–15 популярных районах Москвы, чтобы отчёт не был перегружен.
- Принято решение включить в анализ ограничения арендодателей (по животным и детям), так как это критично для арендаторов.
- Формат MVP согласован как статичный аналитический отчёт с визуализациями. Интерактивный дашборд остаётся опцией на будущее.
- Источники данных: открытые данные ЦИАН и Авито (с учётом лимитов парсинга).
